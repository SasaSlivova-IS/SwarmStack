# SwarmStack command language

The toolkit separates project management from controls for a running agent team.

## Language

**Swarm controls**:
The user-facing interface for team direction, progress, blockers, pause and resume, named /swarm.

**Project commands**:
The interface for project setup and toolkit guidance, named /swarmstack. Each command has a separate procedure.

**Standalone skill**:
An independently invoked workflow such as /grill-with-docs or /code-review, outside the two command interfaces.
