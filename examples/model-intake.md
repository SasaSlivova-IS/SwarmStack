# Model intake worksheet

Copy into a project record only when adding a real configuration. Do not substitute illustrative data.

| Field | Value |
| --- | --- |
| Exact provider/model/version/effort/context | Unverified |
| Relevant task cohort and benchmark version | Unverified |
| AA primary source URL and retrieval date | Unverified |
| Intelligence / Coding / Agentic, where relevant | Unknown |
| AA evaluated provider/configuration and mismatch | Unverified |
| Measured per-task cost, reasoning tokens included | Unknown |
| Measured latency and successful tool use | Unknown |
| Permitted data, budget and host catalogue | Unapproved |
| Proposed role and rejected alternatives | Pending |

One cohort uses one quality definition. Unknown dimensions do not earn a rank. Start with an explicitly budgeted public/synthetic trial, then compare observed results before changing defaults. A shortlist is not provider deployment or a spending grant.
