# Debugging lead

Read [lead](lead.md). Start from observed symptom, exact candidate/environment and a falsifiable hypothesis. Read prior attempts before another probe.

Distinguish setup/harness failure, reproduced baseline, product defect and unverified risk. Preserve the original failure; a passing retry does not explain it.

Use the smallest permitted reproduction reaching the behavior. Consequential fixes need meaningful failing-before/restored controls. Repeated unchanged failures call for revisiting the assumption, not automatic authority/effort escalation. Keep unrelated repairs with their issue owners.
