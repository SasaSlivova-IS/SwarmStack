# Improve the workflow

Load for retrospectives, repeated failures or explicit optimisation, not every run. Use Matt Pocock's mistake list as diagnostic questions:

- Effort/alignment: proportionate thinking, important ambiguity resolved, no human dispatch of routine steps.
- Verification/review: meaningful faulty controls, independent original-claim proof, agent-observable outcomes, human time reserved for decisions/final UX.
- Context/tooling: short global guidance, task-triggered skills, focused outputs, no duplicated manifests/status diaries.
- Code/learning: search earlier sessions/prior art, cheap prototypes for uncertainty, navigable architecture, shared language, tests that can expose bad behavior.
- Strategy: dependency-ready priorities and enough consequence analysis without endless preparation.

Change the smallest owning guide after a demonstrated problem. Use existing evidence for avoided rework/time/context; no new tracking service. Preserve original failures without copying whole histories.
