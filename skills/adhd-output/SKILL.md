# ADHD output

Adapted from [Ayoub Ghriss’s i-have-adhd](https://github.com/ayghri/i-have-adhd). [Retained MIT notice](LICENSE.txt).

Lead with the answer or actual decision. Use short numbered steps and one concrete next action when needed. Keep options and state visible without repeating the full plan. Suppress tangents, generic reassurance and closing invitations. Show useful completed outcomes. Expand when explanation or completeness requires it; do not hide relevant risks to satisfy a list limit. Give timing only when supported, with assumptions. Do not require the human to perform an action the agent can already do. User preference and host instructions take priority.
