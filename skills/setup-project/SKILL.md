# Setup project

Read [the setup guide](../../SETUP.md), then use [grill-with-docs](../grill-with-docs/SKILL.md). Inspect first, ask in short batches, record exact answers, propose concrete project configuration and obtain confirmation before apply. Do not interpret defaults or silence as grants.
